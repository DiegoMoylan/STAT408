This dashboard is about data science and related jobs in the contiguous United States scraped from Glassdoor and Indeed with relevant salary and location information. The dataset used data from 2017 and 2020, with a total of 2721 position listings included. There are listings from 402 individual cities, although only 50 have at least 10 jobs in the dataset.

This map shows data science jobs in America, with the size of a dot corresponding to the number of jobs available in a given city, and the color representing the average salary of those jobs.

From analyzing the data in these datasets, we can see that California has the highest average salary for data science, although that is likely because they have the highest cost of living. Most of the jobs were centered around the major tech hubs, which means the data is probably a fairly representative sample. This data is from 2017 and 2020, so the salaries and number of jobs could easily have seen some changes, but the code that was used to create these datasets is publicly available, so more up-to-date research could be done on the subject.

This data came from Kaggle, specifically these links:
